# Security Policy

## Supported Versions
Current supported branch: `main`

## Reporting a Vulnerability
Please do not disclose vulnerabilities publicly.

Open a GitHub Security Advisory or contact the project maintainer privately.

Include:
- Steps to reproduce
- Impact assessment
- Screenshots or logs if applicable

## Security Principles
- No AI provider secrets stored in the mobile client
- Least-privilege access
- Secure token storage
- Encrypted local storage where applicable
- Responsible disclosure
