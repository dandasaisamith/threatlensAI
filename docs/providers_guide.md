# ThreatLens AI - Riverpod Providers Guide\n\n## Overview\n\nRiverpod is used for state management across the ThreatLens AI application. This guide documents all providers organized by domain.\n\n---\n\n## Provider Architecture\n\n### Provider Types\n1. **StateNotifierProvider** - Mutable state with notifier\n2. **FutureProvider** - Async data fetching\n3. **StreamProvider** - Real-time data streams\n4. **Provider** - Computed/derived state\n5. **StateProvider** - Simple mutable state\n\n---\n\n## 1. Authentication Providers\n\n### auth_provider.dart\n\n```dart\n// Current user state\nfinal currentUserProvider = StateNotifierProvider<CurrentUserNotifier, AsyncValue<AuthUser?>>(\n  (ref) => CurrentUserNotifier(ref.watch(authRepositoryProvider)),\n);\n\nclass CurrentUserNotifier extends StateNotifier<AsyncValue<AuthUser?>> {\n  final AuthRepository _authRepository;\n\n  CurrentUserNotifier(this._authRepository) : super(const AsyncValue.loading());\n\n  Future<void> loadCurrentUser() async {\n    state = const AsyncValue.loading();\n    state = await AsyncValue.guard(() => _authRepository.getCurrentUser());\n  }\n\n  Future<void> logout() async {\n    await _authRepository.logout();\n    state = const AsyncValue.data(null);\n  }\n}\n\n// Authentication state\nfinal authStateProvider = StreamProvider<AuthState>((ref) {\n  final authRepo = ref.watch(authRepositoryProvider);\n  return authRepo.authStateStream();\n});\n\n// Check if user is authenticated\nfinal isAuthenticatedProvider = Provider<bool>((ref) {\n  final currentUser = ref.watch(currentUserProvider);\n  return currentUser.maybeWhen(\n    data: (user) => user != null,\n    orElse: () => false,\n  );\n});\n\n// Get current user organization\nfinal currentOrganizationProvider = Provider<String?>((ref) {\n  final currentUser = ref.watch(currentUserProvider);\n  return currentUser.maybeWhen(\n    data: (user) => user?.organizationId,\n    orElse: () => null,\n  );\n});\n```\n\n### login_provider.dart\n\n```dart\n// Login form state\nfinal loginFormProvider = StateNotifierProvider<LoginFormNotifier, LoginFormState>(\n  (ref) => LoginFormNotifier(),\n);\n\nclass LoginFormNotifier extends StateNotifier<LoginFormState> {\n  LoginFormNotifier() : super(const LoginFormState());\n\n  void setEmail(String email) {\n    state = state.copyWith(email: email);\n  }\n\n  void setPassword(String password) {\n    state = state.copyWith(password: password);\n  }\n\n  void setRememberMe(bool value) {\n    state = state.copyWith(rememberMe: value);\n  }\n}\n\n// Login action\nfinal loginProvider = FutureProvider.family<AuthResponse, LoginCredentials>(\n  (ref, credentials) async {\n    final authRepo = ref.watch(authRepositoryProvider);\n    return authRepo.login(credentials.email, credentials.password);\n  },\n);\n\n// Email validation\nfinal emailValidationProvider = Provider.family<bool, String>((ref, email) {\n  return RegExp(r'^[^@]+@[^@]+\\.[^@]+$').hasMatch(email);\n});\n```\n\n### register_provider.dart\n\n```dart\n// Registration StateNotifier<RegisterFormState> {\n  RegisterFormNotifier() : super(const RegisterFormState());\n\n  void setEmail(String email) => state = state.copyWith(email: email);\n  void setPassword(String Repository Providers\n\n### Repository providers for dependency injection\n\n```dart\n// Threat repository\nfinal threatRepositoryProvider = Provider<ThreatRepository>((ref) {\n  final remoteDatasource = ref.watch(threatRemoteDatasourceProvider);\n  final localDatasource = ref.watch(threatLocalDatasourceProvider);\n  return ThreatRepositoryImpl(remoteDatasource, localDatasource);\n});\n\n// Auth repository\nfinal authRepositoryProvider = Provider<AuthRepository>((ref) {\n  final remoteDatasource = ref.watch(authRemoteDatasourceProvider);\n  final localDatasource = ref.watch(authLocalDatasourceProvider);\n  return AuthRepositoryImpl(remoteDatasource, localDatasource);\n});\n\n// Analysis repository\nfinal analysisRepositoryProvider = Provider<AnalysisRepository>((ref) {\n  final remoteDatasource = ref.watch(analysisRemoteDatasourceProvider);\n  return AnalysisRepositoryImpl(remoteDatasource);\n});\n\n// DeepSeek repository\nfinal deepseekRepositoryProvider = Provider<DeepSeekRepository>((ref) {\n  final datasource = ref.watch(deepseekDatasourceProvider);\n  return DeepSeekRepositoryImpl(datasource);\n});\n\n// User repository\nfinal userRepositoryProvider = Provider<UserRepository>((ref) {\n  final remoteDatasource = ref.watch(userRemoteDatasourceProvider);\n  return UserRepositoryImpl(remoteDatasource);\n});\n```\n\n---\n\n## Provider Naming Conventions\n\n1. **Feature Providers**: `{feature}{entity}Provider` (e.g., `threatDetailProvider`)\n2. **State Notifier Providers**: `{entity}NotifierProvider` (e.g., `currentUserNotifier`)\n3. **Async Providers**: `{action}{entity}Provider` (e.g., `loadThreatsProvider`)\n4. **Stream Providers**: `{entity}StreamProvider` (e.g., `threatStreamProvider`)\n5. **Computed Providers**: `{descriptor}{entity}Provider` (e.g., `filteredThreatsProvider`)\n6. **Repository Providers**: `{entity}RepositoryProvider` (e.g., `threatRepositoryProvider`)\n\n---\n\n## Best Practices\n\n1. **Keep providers focused** - Each provider should have a single responsibility\n2. **Use family modifiers** - For parameterized data fetching\n3. **Leverage caching** - Riverpod caches by default\n4. **Handle loading/error states** - Use AsyncValue for proper state management\n5. **Invalidate when needed** - Use `ref.invalidate()` for manual cache invalidation\n6. **Prefer immutability** - Use `copyWith` and immutable state classes\n\n---\n\n## Example Usage in Widget\n\n```dart\nclass ThreatListWidget extends ConsumerWidget {\n  @override\n  Widget build(BuildContext context, WidgetRef ref) {\n    // Watch providers\n    final threats = ref.watch(threatListProvider(currentFilter));\n    final isConnected = ref.watch(isConnectedProvider);\n\n    return threats.when(\n      data: (threatList) => ListView(\n        children: threatList.map((threat) => ThreatTile(threat: threat)).toList(),\n      ),\n      loading: () => const CircularProgressIndicator(),\n      error: (error, stack) => ErrorWidget(error: error),\n    );\n  }\n}\n```\n"
